# Lancer-OS Theme for Obsidian

A high-contrast, aggressive, sci-fi terminal theme for Obsidian. 
Built specifically to emulate the UNION_OS look and feel for the Lancer TTRPG.

## Features
- Deep black/grey background for minimal eye strain
- Aggressive neon orange (`#ff4500`) primary accent for headers, structural icons, and properties
- Complementary bright cyan (`#00d8ff`) secondary accent for active states, links, and folder prefixes
- Specialized formatting for directories (`DIR //`) and files (`::`) to match a terminal aesthetic
- Custom styles for Dataview tables, Callouts, and internal links

## Installation
1. Download `theme.css` and `manifest.json`.
2. Place them inside `.obsidian/themes/Lancer-OS/` in your vault.
3. Select "Lancer-OS" in your Obsidian Appearance settings.
